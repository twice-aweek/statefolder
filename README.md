StateFolder - desktop-приложение на Flutter для учета задач по проектам, сравнения дедлайнов с фактическими датами сдачи и визуального анализа отклонений.

## Что умеет

- Несколько проектов во вкладках.
- Автосохранение данных между запусками.
- Ручное добавление задач: задача, исполнитель, дедлайн, дата завершения.
- Импорт задач из `.xlsx`.
- Экспорт таблицы задач и сводки в Excel.
- 3D-график отклонений по задачам и исполнителям.
- Сводка по проекту: всего задач, раньше срока, в срок, опоздания, среднее отклонение.

## Скачать

Готовая Windows-сборка лежит в репозитории:

```text
releases/statefolder-windows-x64.zip
```

Чтобы запустить:

1. Скачайте архив по кнопке сверху.
2. Распакуйте папку в любое место.
3. Запустите `statefolder.exe`.

Важно: `statefolder.exe` должен лежать рядом с папкой `data`, файлом `flutter_windows.dll` и `native_assets.json`. Поэтому переносите или архивируйте всю распакованную папку целиком.

## Как пользоваться

1. Создайте проект через `+` во вкладках.
2. Нажмите `Создать` или `Добавить данные`.
3. Заполните задачу, фамилию исполнителя, дедлайн и дату завершения.
4. Нажмите `Добавить запись`, чтобы добавить строку.
5. Нажмите `Построить график`, чтобы открыть 3D-визуализацию.
6. В графике переключайте проекты вкладками, меняйте режим вращения/перемещения и открывайте сводку кнопкой в правом верхнем углу.

## Хранение данных

Данные сохраняются автоматически в JSON-файл в папке документов пользователя:

```text
Documents/statefolder_state.json
```

Это значит, что после закрытия приложения проекты и записи не пропадают. Excel-файлы используются отдельно: для импорта, экспорта таблицы и выгрузки сводки.

## Формат Excel для импорта

Приложение читает первый лист `.xlsx`. Первая строка считается заголовком, дальше ожидаются колонки:

| Колонка | Значение |
| --- | --- |
| A | Задача |
| B | Фамилия |
| C | Дедлайн |
| D | Дата завершения |

Даты поддерживаются как Excel-даты и как текст в формате `dd.MM.yyyy`, `dd/MM/yyyy`, `dd-MM-yyyy` или ISO.

В папке `examples` есть несколько тестовых `.xlsx`, которые можно использовать для проверки импорта.

## Разработка

Требования:

- Flutter 3.38+
- Dart 3.10+
- Windows toolchain для сборки desktop-версии

Команды:

```powershell
flutter pub get
flutter analyze
flutter test
flutter build windows --release
```

После сборки готовое приложение будет здесь:

```text
build/windows/x64/runner/Release/statefolder.exe
```
